# 产地占比校正分析方法

逐箱汇总识别器标签会把系统性混淆当成产地构成的真实变化，逐箱复核又太慢。`GET /correction`
在总体占比（quantification）层面做校正：**不替任何单箱给出更肯定的标签**，只估计各时期
产地构成及其不确定性。本文档说明口径、方法、输出与限制；数据表约定见 `docs/domain.md`。

## 估计目标与口径

* 分析按**识别器版本**分段，不同版本不混用混淆结构。
* 时期按到货业务日归入 ISO 周（`period=week`，默认）或月份（`period=month`）。
* 每个时期给出两种口径的产地构成：`count`（箱数占比）与 `weight`（重量占比）。
  复核设计入选概率按箱定义，两种口径共用同一套按箱估计的混淆结构；重量口径通过对
  各箱重量加权的解混得到，不把入选概率误用于公斤。
* 每个单元（包装线×品种）单独估计混淆结构，时期占比为各单元估计按单元规模的加权和。

## 方法

### 混淆结构估计

复核样本按设计入选概率做 Horvitz-Thompson 加权（权重为入选概率的倒数），估计
`P(预测标签 | 真实产地)` 的每一行。某单元某产地无复核证据时，按
单元 → 包装线 → 品种 → 全局 逐级回退借用证据，每行的来源层级记录在
`cells.*.confusion.row_level`；全局也无证据的类标记为 `unidentified`，其混淆行退化为
均匀分布并在 `notes` 中明确警示。估计用矩阵经 Dirichlet 平滑（`smoothing_alpha`，
默认 0.5），诊断用未平滑行。

### 占比解混

每个时期×单元在单纯形内用 EM 解混（标签平移模型：观测标签分布 = 混淆结构 × 真实占比），
**占比不会出现负值**，不需要事后截断。混淆结构由截至证据截点的全部复核合并估计，
比例逐期变化——这正是"只变产地比例、识别机制没变"的前提，其检验见下。

### 联合不确定性

分层自助法同时重抽两类数据：复核样本（按设计层）与到货箱（按时期×单元），
重复全部估计流程。每个时期输出占比向量的：

* `covariance`：联合协方差矩阵（含类顺序）；
* `se` 与 `ci95`：各产地的边际标准误与 95% 百分位区间；
* `joint95_halfwidth`：同时置信半宽（max-|t| 联合带的逐类半宽），
  用于多产地、多时期的联合解读，避免逐区间分别解读造成的过度自信。

不确定性同时包含复核样本（混淆结构）与到货过程（标签分布）两部分波动；
把当期到货视为完整总体时，可只关注前者，但报告不做此区分。

### 前提检验

`checks` 下有两项诊断，检验"只有产地比例变化、识别机制没变"：

* `mechanism_stability`：复核的（真值 × 预测）列联表在前后两个时间窗
  （按复核箱到货日中位划分）是否一致，单元内置换检验。这是前提的**直接**检验，
  能发现任何改变混淆结构的机制漂移。
* `score_moment_consistency`：各期平均识别分数能否由固定机制按估计比例重新混合
  解释。参数化自助在原假设下重抽复核并模拟未复核箱的分数（复核箱作为总体中
  已观测成员保持不变）。该检验以全部复核的合并机制为参照，能发现重新混合无法
  解释的相对漂移；对均匀污染参照系的整体漂移不敏感，也无法发现与比例变化
  等价的漂移（如标签置换）——这些由稳定性检验经复核真值把关。

p 值小于 0.05 标记为 `flag`，否则为 `consistent`；证据或重抽样次数不足时为
`unavailable`。**不显著不等于证明稳定**，矩检验在现有样本量下只能发现较剧烈的
机制失效。

### 可识别性

混淆矩阵接近奇异、或真值类数多于标签数（识别器标签集外的新产地并入 `other` 后
必然如此）时，占比向量不存在唯一点估计。此时报告**不强行求逆**，而是给出：

* `cells.*.diagnostics`：奇异值、零空间维数、条件数、行全变差距离；
* `merged`：识别行为几乎相同的产地合并成组（任一单元不可区分即并集，保守口径），
  合并比例可识别，附自助区间——**合并比例是这些产地唯一可信的汇报口径**；
* `bounds`：给定观测标签分布与混淆结构，每类占比的代数可行范围
  （线性规划，按单元求解后加权汇总）。这是结构范围，不含抽样不确定性，
  与自助区间互补；
* `notes`/`warnings`：无法判断时给出原因（如"类别 X 无复核证据"
  "真值类数超过可区分方向"）。

含 `other` 时点估计沿零空间方向由初始化决定、不可解释，相应时期会给出警示，
请以合并比例与可行范围为准。`known_only_shares` 为不纳入新产地证据的对照口径
（未知产地质量被摊入已知类），与主口径并列以便评估敏感性。

### 新产地

复核确认类别超出识别器标签集时，全部并入 `other` 一类（`other.sources` 记录原始
确认类别与条数），其混淆行由现有证据全局合并估计。`other` 与相似已知类通常只能
合并报告；证据为零时不纳入 `other`，已知类口径即主口径。

## 证据截点与可追溯

* `as_of`（可选，带时区的 ISO 时间）：仅使用 `confirmed_at` 不晚于截点的复核。
  之后的确认不参与估计，保证不能用事后证据改写当时可用证据下的分析。
  查询串中的 `+` 需百分号编码为 `%2B`。
* `provenance` 记录：数据指纹、估计器版本、生成时间、证据截点、参数、
  所用复核样本的完整 ID 清单与最晚确认时间、各识别器版本的已知类与样本量、
  到货日范围。研究备注（`POST /cases`）可保存报告副本用于追溯。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `period` | `week` | 时期粒度：`week`（ISO 周）或 `month` |
| `as_of` | 无 | 证据截点（带时区 ISO 时间），之后确认的复核不参与 |
| `replicates` | 500 | 自助重抽次数，0 至 5000；0 表示跳过不确定性评估 |
| `seed` | 20261115 | 随机种子，相同种子与输入得到相同结果 |

## 输出结构

```
status                  ok | evidence_insufficient
provenance              数据指纹、估计器版本、证据截点、复核样本清单、参数等
versions.<版本>
  status                ok | evidence_insufficient（附 reason）
  classes               已知类 + other（如有新产地证据）
  other                 新产地证据与来源
  cells.<线|品种>       混淆矩阵、行来源层级、可识别性诊断、警示
  periods.<时期>
    boxes / weight_kg   该期箱数与总重量
    count / weight      shares（主口径）、naive_shares（未校正对照）、
                        known_only_shares、se、ci95、joint95_halfwidth、
                        covariance、bounds
    merged              合并组及其比例与区间
    warnings            该期警示
  checks                两项前提检验
  notes                 版本级可识别性与新产地警示
```

`naive_shares` 是直接汇总识别标签的未校正占比，用于对照校正幅度。所有占比非负、
和为一；证据不足时返回结构化原因而非强行估计。

## 限制

* 校正依赖复核设计的代表性：入选概率必须已知且为正，设计不随时间变化
  （稳定性检验的分窗比较依赖后者）。
* 混淆结构假设在证据截点内稳定；稳定性检验不显著不等于证明稳定。
* 矩检验参照系由全部复核合并估计，对均匀污染参照系的整体漂移不敏感。
* 新产地证据稀少时，`other` 相关量只有宽泛的可行范围，这是数据所限而非保守过度。
* 占比是时期总体（到货过程）层面的推断，不构成对任何单箱产地的判断。
