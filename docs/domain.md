# 分类器漂移下的产地占比校正资料约定

复核按箱抽样，无需对同一箱去重。真实产地只在 reviews 中可见，模型最高分标签不是真值。分数键与模型标签版本对应，未知产地不会凭空获得一个识别分数。复核概率适用于箱，不自动适用于公斤。日期代表到货业务日，确认时间在其后；历史研究的证据截点决定可读取的复核真值。

## 数据表

### `classes`

已知类仅覆盖原识别器标签，人工复核可以给出其他产地。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `label` | `text` |
| `model_version` | `text` |

### `boxes`

每箱一行，分数为既有识别器输出，不是人工真值。箱数和重量分别定义不同目标占比。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `day` | `date` |
| `line` | `text` |
| `species` | `text` |
| `weight_kg` | `number` |
| `model_version` | `text` |
| `scores` | `json` |
| `predicted` | `text` |

### `reviews`

确认类别允许超出已知标签集；confirmed_at 是首次可知真值的时刻，不是到货日。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `box_id` | `text` |
| `confirmed_class` | `text` |
| `confirmed_at` | `time` |

### `sampling`

每箱在复核设计中的已知入选概率，不是模型置信度；未抽中的箱也有设计记录。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `box_id` | `text` |
| `selection_probability` | `number` |
| `stratum` | `text` |

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。
